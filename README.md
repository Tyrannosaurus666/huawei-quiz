# 华为知识测验程序（驾考宝典版）

从 Word 文档《早点休息(2).docx》中提取题库，做成类似驾考宝典的交互式测验程序：
随机出题、数字答题、答完立即显示正确答案，支持单选/多选/判断三种题型。

## 文件说明

| 文件 | 说明 |
|---|---|
| `早点休息(2).docx` | 原始题库文档，黄色高亮标记为正确答案 |
| `parse_questions.py` | 题库解析器：从 docx 提取题目/选项/答案，生成 `questions.json` |
| `questions.json` | 解析后的题库（422 题：单选 160 / 多选 105 / 判断 157） |
| `huawei_quiz.py` | 主程序（驾考宝典版），运行这个即可 |
| `quiz_final.py` | 旧版程序（仅支持单选，可忽略） |
| `test_quiz.py` | 自动化测试脚本 |

## 使用方法

```bash
python huawei_quiz.py
```

### 主菜单

1. 随机练习（全题库随机顺序）
2. 随机 20 题小测
3. 只练选择题
4. 只练判断题
5. 错题重练（答错的题自动进入错题本）
0. 退出

### 答题方式

- **单选题**：输入 1-4 选择对应 A/B/C/D（选项数量按实际题目显示）
- **多选题**：输入多个数字，连写（`13`）、空格（`1 3`）、逗号（`1,3`）均可
- **判断题**：输入 1 = 正确，2 = 错误
- 任何位置输入 `q` 退出当前练习

## 重新生成题库

如果修改了原始 docx，重新运行解析器：

```bash
python parse_questions.py
```

## 注意事项

- Windows 控制台若中文显示乱码，程序已自动切换 UTF-8 编码
- 题目中"正确/错误"答案有两种排版（题尾内嵌 / 独立段落），解析器均已支持
- 部分多选题有 5-7 个选项（A-G），程序按实际数量显示
